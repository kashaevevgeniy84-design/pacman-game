# Искра

Браузерная аркада в духе классических игр с лабиринтом. Соберите все искры, избегайте четырёх стражей и переходите на следующий уровень. Лабиринт, персонажи и оформление созданы из собственных простых форм, без изображений Pac-Man.

## Запуск

Откройте **index.html** в современном браузере. Установка, сборка, сервер и интернет не нужны. Сохраните `index.html`, `styles.css` и `game.js` в одной папке.

### Через GitHub Pages

Сайт рассчитан на адрес **https://kashaevevgeniy84-design.github.io/pacman-game/**. Этот адрес начнёт работать после включения Pages и успешного развёртывания.

1. Откройте репозиторий [kashaevevgeniy84-design/pacman-game](https://github.com/kashaevevgeniy84-design/pacman-game).
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
4. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
5. Дождитесь завершения развёртывания **pages build and deployment** на вкладке **Actions**. В **Settings → Pages** появится ссылка **Visit site**.
6. Откройте сайт и нажмите **«Начать игру»**. Для управления используйте стрелки, для паузы — пробел.

Сайт использует относительные пути и работает в подпапке `/pacman-game/`. Файл `.nojekyll` отключает обработку Jekyll. Сборка, Node.js, npm, сторонние библиотеки и дополнительные секреты для публикации не нужны. Следующие изменения в `main` будут публиковаться автоматически.

### Скачать на компьютер

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте весь архив.
3. Откройте `index.html` из распакованной папки в браузере.

Альтернатива: откройте файл `iskra.html` в репозитории, нажмите **Download raw file**, сохраните файл и откройте его в браузере. Эта самостоятельная версия содержит встроенные CSS и JavaScript и не требует других файлов.

### Проверить через локальный сервер

Если удобнее использовать HTTP, из папки проекта выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/index.html`. Сервер нужен только для этого способа проверки; обычный запуск `index.html` обходится без него.

## Управление

| Действие | Клавиши |
| --- | --- |
| Начать или продолжить | Enter или кнопка на поле |
| Движение | Стрелки или WASD |
| Пауза / продолжение | Пробел, P или кнопка «Пауза» |
| Поставить на паузу | Escape |
| Новая игра | Кнопка с круговой стрелкой |

На телефоне доступны экранные стрелки. Персонаж продолжает движение сам; нажатый поворот запоминается до ближайшего доступного прохода. При переключении вкладки игра автоматически ставится на паузу.

## Правила

- Маленькая искра: **10 очков**. Большой заряд: **50 очков**.
- Заряд позволяет временно догонять стражей: **200, 400, 800 и 1600 очков** за последовательные поимки. Пойманный страж возвращается на свою стартовую площадку.
- В начале три жизни. Столкновение без заряда отнимает одну. Собранные точки и счёт сохраняются; после возрождения есть две секунды защиты.
- Соберите все точки и заряды для следующего уровня и бонуса **500 очков**. Скорость постепенно растёт, время действия заряда сокращается с 7 до 4,5 секунды. Жизни между уровнями сохраняются.
- Рекорд сохраняется в `localStorage`, если браузер разрешает локальное хранение. Без него игра также работает, но рекорд хранится только до закрытия страницы.

## Файлы

- `index.html` — интерфейс.
- `styles.css` — адаптивное оформление.
- `game.js` — Canvas-отрисовка, движения, поиск пути стражей и состояния игры.
- `iskra.html` — самостоятельная копия игры со встроенными стилями и скриптом.
- `.nojekyll` — публикация статических файлов через GitHub Pages без обработки Jekyll.

Используются только стандартные API браузера. Внешних библиотек, шрифтов, ресурсов и запросов к сети нет.
